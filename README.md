# Play Smarter Bot 🎮

A Telegram bot that provides daily gaming tips, tracks user progress, and builds a community of gamers who want to improve their skills.

## Features

- 📅 **Daily Gaming Tips** - Get a new tip every day
- 📊 **Track Stats** - Monitor your points, streaks, and progress
- 🏆 **Leaderboard** - Compete with other players
- 📂 **Categories** - Browse tips by category:
  - Strategy Tips
  - Aim Improvement
  - Mental Game
  - Settings Optimize
- 🎯 **Points System** - Earn points for learning
- 🔥 **Streak Tracking** - Build daily streaks

## Tech Stack

- Python 3.9+
- python-telegram-bot v20.0
- PostgreSQL (for production)
- Environment variables for configuration
