# Play Smarter Bot 🎮

A Telegram bot that provides daily gaming tips, strategies, and insights to help players improve.

## Features
- 🎯 Daily gaming tips
- 📂 Strategy categories (Aim, Strategy, Mental, Settings)
- ⭐ Point system
- 🔥 Streak tracking
- 🏆 Leaderboard competition
- 📊 Personal statistics

## Commands
- `/start` - Main menu
- `/tip` - Get daily gaming tip
- `/categories` - Browse tip categories
- `/stats` - View your stats
- `/leaderboard` - View top players
- `/help` - Help menu

## Deployment
Deployed on Railway with GitHub integration.

## Tech Stack
- Python 3.11+
- pyTelegramBotAPI
- Railway
